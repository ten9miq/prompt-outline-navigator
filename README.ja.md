# Prompt Outline Navigator

[English](README.md) | [日本語](README.ja.md)

ChatGPTとGeminiの会話に、リアルタイムで更新される目次とナビゲーション用サイドバーを追加します。

Prompt Outline Navigatorは独立したプロジェクトであり、OpenAIやGoogleとの提携や、両社による承認を受けたものではありません。

**リリース：** Gemini対応を含む[v1.7.0](https://github.com/ten9miq/prompt-outline-navigator/releases/tag/v1.7.0)をGitHubで公開しました。正式ZIPとチェックサムを添付済みです。2026-10-24にChromeウェブストアへ1.7.0を提出し、現在は審査待ちです。ストアの公開済みバージョンは引き続き1.6.3です。

## 対応サイト

| 対象 | ChatGPT | Gemini |
| --- | --- | --- |
| サイトアクセス | `https://chatgpt.com/*`、`https://chat.openai.com/*` | `https://gemini.google.com/*` |
| 会話の目次 | 通常・GPT・プロジェクト会話 | 描画済みの会話履歴 |
| その他の目次対象 | Spaceのアクティブな文書とdotのフィード | Canvasとノートブックは目次対象外 |
| 幅補正 | 初回・プロジェクトホームの入力欄を含む回答と入力欄 | 通常の`/app`会話の回答・送信済み質問・入力欄・回答操作行 |
| DOMから外れた履歴 | 発見済み項目を保持し、復旧を試行 | 切断したターンの保持・復旧は未対応 |

## 機能

- サイトのアプリルートを移動せず、画面最上部にサイドバーを表示します。左境界にホバーするとChatGPTのサイドバーと同じ幅変更カーソルと控えめな境界色を表示し、ドラッグして幅を変更でき（初期値200px、範囲160～600px）、横幅と開閉状態を端末内に保存します。狭いウィンドウでは保存幅を上書きせず表示幅だけ制限します。境界のダブルクリックで表示モードを変えず幅を200pxへ戻します。ホバーモードでは画面右端20pxへのホバーで本文に重ねて一時表示します。本文幅を変えずに目次を選択でき、マウスが外れると再び隠れます。右上のピンボタンで常時表示とホバーモードを切り替え、現在のモードをピン／斜線付きピンで示します。常時表示に戻すと予約幅を戻します。独立したTOCボタンは表示しません。境界にフォーカスして左右キーで幅変更、Enterで非表示にもできます。Homeは通常の上への移動として扱い、横幅を変更しません。
- URL許可リストではなく本文のDOM構造で、ChatGPTの通常・GPT・プロジェクト会話、開いているSpace文書、dotのメッセージ一覧と、Geminiの会話履歴を検出します。文書プレビュー、ナビゲーション、引用返信の操作部分、入力欄は除外します。添付だけの入力にも対応します。予約幅は保存された手動の開閉状態だけに従い、ホバーで一時表示しても変化しません。保存状態はページ遷移・設定画面・オーバーレイ表示でも維持します。対応本文のないページでは同じ目次枠に項目がないことを表示します。タイトル部分を下へドラッグすると、予約幅を変えずに目次を一時的に移動できます。タイトル部分のダブルクリックで、横幅とホバーモードを維持したまま上下位置だけ最上部へ戻します。タイトルにフォーカスしてHomeキーを押した場合は横幅を変えずに最上部へ戻ります。上下キーでも10pxずつ移動できます。位置は保存せず、ページ遷移や再読み込みで最上部に戻ります。
- ChatGPTの会話内の文章エディタは会話全体の目次を置き換えず、元のPROMPT配下に表示します。エディタ項目にはメール件名、レベル1の見出し、本文の最初の空でない1行（明示的な改行を考慮し、最大80文字）の順でラベルを使います。正式な見出し（ARIA見出しを含む）を優先し、エディタ内に見出しがない場合だけ、段落全体が太字になった短い番号付き段落を節項目にします。通常の強調、引用・リスト・表の内容、プレビュー、入力欄はこの補助判定から除外します。複数エディタ、編集、再描画に対応し、独立した文書は専用の目次を維持します。
- ChatGPTでは目次の表示や目次対象の判定とは独立して、会話の回答本文と入力欄の幅補正を常に有効にし、Chat・Work・プロジェクトホームの初回入力欄にも適用します。URLや配置名ではなく、共通の`data-chatgpt-composer`／`data-thread-find-composer`属性で入力欄を検出し、同じペイン内で入れ子になった親要素の幅制限も補正します。複数入力欄と属性の変更にも対応します。文章作成用エディタを開いても幅補正を解除しません。ペインやダイアログの境界、無関係な設定欄、Space文書とdotは専用の配置を維持します。この環境にないWorkspace Agent設定画面は未検証で、同じ共通属性を持つ入力欄だけが補正対象になります。
- 幅の広い表や整形済みテキストが隠れないよう、対象を限定したスクロールと折り返しを適用します。
- `MutationObserver`を使用し、変更された会話ターンと見出しだけを更新します。
- ChatGPTが過去のターンを一時的にDOMから外して再マウントしても、発見済みの目次項目、会話内の順序、最初に取得したプロンプトラベルを保持し、選択時に対象ターンを読み込みます。通常クリックは滑らかに移動し、スクロール完了後に位置を補正します。仮想化した移動先の復旧は即時移動で行います。過去の履歴の読み込みで記憶した座標がずれた場合は、現在描画されているターンの順序から探索範囲を絞り込みます。新しいクリックやユーザーのスクロールで保留中の補正を中止します。
- 現在の仮想化レイアウトや保持済みの過去グループから、上側の会話ターンがDOMから外されていると判定できる場合だけ「Go to conversation start」を表示します。すべて描画済みの本文をスクロールするだけでは表示しません。選択すると先頭へスクロールして過去ターンの再描画を促し、再描画後に消えます。この判定はChatGPTのDOM構造に依存し、会話履歴APIは使用しません。
- 判定線を含む回答領域を先に確定し、その回答内だけで直前の見出しを追跡します。ChatGPTがDOMを一時的に再マウントしている間は、離れたPROMPTへ飛ばず現在の選択を保持します。
- ページ移動中は現在位置に対応するTOC項目へ自動追従します。新しい項目の追加時は、TOCが末尾にあった場合だけ新しい末尾へ追従し、途中を閲覧していた場合はTOCのスクロール位置を維持します。
- HTMLのように見える文字列を含め、プロンプトと見出しを`textContent`で安全に描画します。目次項目は最大2行で省略表示し、ラベルにホバーすると表示上の省略前のテキストを確認できます。
- 見出し階層とプロンプトグループの折りたたみ、ライト・ダーク別に調整した階層色と選択中のPROMPT色、SPA内のページ遷移に対応します。

ChatGPTの会話領域の属性値が真偽値でも会話IDでも検出し、表示中の明示的な会話ルートを優先します。必要な場合は、会話用と明示されたスクロール領域を使います。役割属性やメッセージIDが遅れて付く場合も回答本文から検出します。入れ子の要素や再描画はメッセージの識別情報で重複を防ぎ、入力の認識が遅れた場合はラベルを訂正します。同じ入力IDの取得済みラベルは保持します。入力が一時的に見つからなくても描画済みの回答を目次に残します。

目次への包含と移動可能な状態を共通の判定で扱います。ChatGPTでは仮想化や同じ会話内でのルート置換で過去項目を保持し、接続中の非表示の別回答や同じ応答位置で置き換えられた旧回答は除去します。描画中のターンがまばらでも会話内の順序を維持します。通常回答のトークン追加では目次を再構築せず、エディタの連続更新は120ms間隔にまとめて、影響した回答だけを再処理します。これらの対策は描画済みDOMに依存し、会話履歴は取得しません。

分岐したローカル会話内の読み取り用表示など、Markdownが生テキストで表示される文章ブロックでも、文書項目と`#`～`######`の見出し項目を生成します。コードフェンス内は除外します。本文へ要素を挿入したり文章を書き換えたりせず、テキスト範囲を使って見出しの行へ移動します。生テキストとリッチエディタの表示が切り替わった場合も目次を再構築し、非表示の分岐コピー、プレビュー、入力欄は対象に含めません。

文章の部分修正によって元文書が折りたたまれても、その見出しを元のPROMPT配下に保持します。例外として扱うのは文書自身の展開ボタンに結び付いた本文領域だけで、無関係な非表示内容は含めません。その見出しを選ぶと元文書を展開し、再描画を待ってから該当位置へ移動します。折りたたまれた見出しは、展開するまで現在位置の追跡対象から除外します。

### Geminiの動作と制約

Geminiでは送信済みの質問と回答見出しをグループ化し、見出しの逐次更新・再描画・SPAでの会話切り替え・ライト／ダークテーマに追従します。読み上げ用ラベル、思考パネル、ツールバー、ナビゲーション、入力欄は目次へ含めません。添付のみの入力もグループとして扱います。

通常の`/app`会話では、回答・送信済み質問の吹き出し・初回と既存会話の入力欄・回答操作行がペインの利用可能幅を使います。回答外枠には片側32px、ビューポート幅700px以下では16pxの内側余白を追加し、Gemini標準のブロック内余白は維持します。リスト・引用・コード・表の構造を保ち、標準の入力欄のmarginも幅に含めて、編集領域やボタンをペイン内へ収めます。

Canvasの内容とノートブックは目次生成・拡幅の対象外です。共存時の配置は確認しており、モバイルのCanvas全画面表示中は保存モードを変えずに目次とホバー検出領域を一時的に隠し、閉じると元のモードへ戻します。狭い埋込みコードCanvasではヘッダーを折り返し、共有・全画面表示・閉じる操作を選択できるようにします。

実画面では20ターン・回答本文約3.2万字・58見出しで更新・移動・順序を確認しました。全ターンは`content-visibility:auto`を使ってDOMに残り、DOM削除型の仮想化は発生していません。本当に切断されたGeminiターンの項目の**保持・復旧は未対応**で、ChatGPTと同等の履歴復旧を保証する検証ではありません。確認範囲と別拡張のショートカット競合は[Gemini対応と検証](docs/GEMINI_SUPPORT.md)を参照してください。

## 開発

```powershell
npm test
npm run test:unit
npm run test:browser
npm run check
```

`npm test`はNode.jsの単体テストとPlaywrightのブラウザーfixtureテストを実行します。ブラウザーテストにはNode.js 20以降が必要です。初回に`npx playwright install chromium`でPlaywright用Chromiumをインストールしてください。

コンテンツスクリプトは、共通ヘルパー、本文検出用adapter、サイドバーUI、会話同期、移動処理、現在位置追跡、`content.js`の初期化処理に責務を分けています。コードを追加・移動するときは、`manifest.json`の読み込み順を維持してください。

[目次生成の信頼性監査と回帰検証表](docs/TOC_RELIABILITY.md)に、本文の状態判定、旧実装との比較、維持すべき状態遷移、fixtureと実ページ検証の境界を記録しています。`tests/toc-lifecycle.spec.js`では一連の状態遷移と、差分更新が無関係な回答に及ばないことを確認します。

Chromeの「拡張機能」画面でデベロッパーモードを有効にし、このディレクトリを「パッケージ化されていない拡張機能を読み込む」から選択します。

ChatGPT実画面を確認しながら開発したWindowsの手順は[Chrome DevTools MCPによる開発・検証](docs/CHROME_DEVTOOLS_MCP.md)を参照してください。専用Chromeプロファイル、Codexの接続設定、拡張とページの再読み込み、配置とスクロールの実測、Consoleエラーの帰属確認をまとめています。

実画面の調査・検証には、その専用Chrome（`%LOCALAPPDATA%\Chrome-MCP-Test`、debug port `9222`）をChrome DevTools MCP経由で使用します。必要ならエージェントが起動し、同じ専用Chromeが起動済みなら接続先を確認して再利用します。対象URLはそちらで開き、ユーザーが明示指定しない限り、Braveなど普段使いのブラウザーの既存タブは使用しません。接続できない場合は既存タブへ切り替えず、ドキュメントの起動・接続手順を確認します。ログインや認証チャレンジは専用Chrome内でユーザーが行います。

PlaywrightテストはChromium内の模擬ChatGPT会話URLで`tests/browser-fixture.html`を配信し、匿名化した会話DOM、サイドバー初期化、安全なテキスト描画、差分更新、仮想化ターンの保持、ピンの切り替えと、境界・タイトルの初期化がホバーモードを維持することを確認します。未知のURLでの文書・メッセージadapter、プレビュー除外、初回入力欄の幅と最初のメッセージ生成時のDOM遷移、上下移動、保存状態が開・閉の両方でページ遷移やモーダル・非モーダル表示が設定を書き換えず、目次の表示状態と予約幅を維持すること、添付だけの入力に続く長い回答、会話ルートの置換も確認します。`tests/layout-fixture.html`はビューポート幅1280px・1920pxで会話・非対象画面の幅と、サイドバー上端の余白を検証します。インラインでビューポート幅が指定されたアプリ枠と、会話ルート外の入力欄を含む配置も追加で検証します。レイアウトfixtureはブラウザーで手動確認できます。これらの確認はChatGPT実画面での検証を代替するものではありません。

回帰テストでは、会話IDを持つ会話領域、メッセージ要素が入れ子になった添付のみの入力、本文・役割・エディタ属性の遅延付与、入力の欠落、同一ターン内の複数回答、同じ要素での会話切り替え、エディタの連続更新中の目次更新も確認します。

`tests/gemini.spec.js`では匿名化したGeminiのDOM fixtureを使い、入力と回答の対応、回答本文の見出しだけの抽出、見出し・プロンプトへの移動、逐次更新、回答の置換・再描画、添付のみの入力、履歴領域の属性の遅延付与、SPA遷移、ライト・ダークテーマ、常時表示・ホバー表示・狭い画面での回答・質問・入力欄の幅とCanvas・ノートブックの除外を確認します。fixtureとGemini実画面の検証は区別します。展開済み拡張を再読み込みした後は、既存のGeminiタブも再読み込みしてください。更新時には`gemini.google.com`へのアクセス許可を求められる場合があります。

### Chrome Web Store用パッケージ

manifestから参照される実行ファイルとライセンスだけを含む、審査用の最小パッケージを生成します。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-store-package.ps1
```

スクリプトは`npm run build`（JavaScriptの構文検査、unit test、browser test）を実行し、ZIPの完全なファイル一覧と各ファイルの内容を元のソースと照合してSHA-256ハッシュを表示します。出力先は`dist/prompt-outline-navigator-<version>-chrome-web-store.zip`です。`-Review`を付けると末尾に`-review`を付けた確認用ZIPを生成します。`-SkipTests`は、変更のないruntimeの検証が成功した直後だけ使用してください。版数は`main`へのマージ直前に一度だけ更新し、公開済みの版数を使った確認用ZIPを更新提出に使わないでください。

掲載原稿、プライバシー申告、個人情報を含まないサンプル画像と公開前の手順は[公開準備](docs/RELEASE.md)を参照してください。サンプル画像は`node scripts/capture-store-screenshots.js`で再生成できます。

公開済みの[v1.6.3リリース](https://github.com/ten9miq/prompt-outline-navigator/releases/tag/v1.6.3)はChatGPTの保持済み履歴への移動を修正したものです。当時のZIPは`dist/prompt-outline-navigator-1.6.3-chrome-web-store.zip`で、Gemini対応は別の[v1.7.0](https://github.com/ten9miq/prompt-outline-navigator/releases/tag/v1.7.0)で公開しています。Gemini更新版には`1.7.0`を使います。正式ZIPと残りの公開手順は[リリース準備](docs/RELEASE.md)を参照してください。[1.6.2リリース](https://github.com/ten9miq/prompt-outline-navigator/releases/tag/v1.6.2)では目次の検出・部分修正・メッセージ識別・仮想化履歴の扱いを改善しました。

前版`1.6.0`では、所有者の依頼により検証済みのストア用ZIPを準備しました。ZIPは`dist/prompt-outline-navigator-1.6.0-chrome-web-store.zip`です。[GitHubリリース](https://github.com/ten9miq/prompt-outline-navigator/releases/tag/v1.6.0)からダウンロードできます。Chromeウェブストアへの提出は別途行います。
